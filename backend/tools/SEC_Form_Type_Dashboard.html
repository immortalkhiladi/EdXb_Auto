How to use

  1. Form Library: click any form type for its full requirement card (purpose, trigger, deadline, items, exhibits, structured data, 2026 notes).
  2. Study: read a card, then take the auto-generated quiz.
  3. Compare: pick up to 4 form types; rows that differ are flagged and each form's trigger is explained.
  4. Validate Upload: drop a filing (primary .htm, exhibits, EDGAR .txt, Form 4 XML or a .zip). Failures appear in one tab, passed items in another, exhibit hyperlink analysis in a third.
  5. Filing Fees: exhibit fee reference table, how Exhibit 107 fees work, per-form guidance, worked examples, a branching fee-processing workflow and a fee quiz.
  6. XBRL TRAINING: 18 modules — US GAAP vs IFRS, 10-Q / 10-K / 20-F tagging, elements, contexts, dimensions, validation, searchable element reference tables, exercises and quizzes.
  7. Rules & 2026 Updates: every check with its citation, the 2026 changes list, and a JSON box for your own checks.
